# Portfolio curation

The originals remain on disk. `sync_database.py` excludes metadata entries with `hidden: true` or `supportingOnly: true` from the gallery and its counts.

To restore a piece, remove its `hidden` flag in `assets/data/asset-metadata.json`, then run `python sync_database.py`.
